# **Programmatische Werkzeuge & Heuristiken (Pre-LLM)**

## **1\. Datenbeschaffung**

* GitHub API / GraphQL für PRs, Kommentare und Issue-Links.  
* Diff-Parsing (unidiff o.ä.) für genaue Zeilenzuordnung.

## **2\. Rauschunterdrückung & Deduplizierung**

* RegEx für Trivial-Rauschen.  
* **MinHash / LSH:** Extrem schnelles Clustering von ähnlichen Copilot-Vorschlägen vor der Vektorisierung.  
* State-Maschine: GitHub-Status-Checks (Resolved-Status vs. Commit-Präsenz).

## **3\. Code-Struktur & Lifecycle**

* **Abstract Syntax Trees (AST):** Überprüfung, ob Code-Entitäten (Klassen/Funktionen aus alten Kommentaren) im aktuellen Main-Branch noch existieren.  
* Git Blame: Identifikation von massiven Refactorings.

## **4\. Speicherung (Wissensrepräsentation)**

* Graph-Datenbank (Kùzu, Neo4j) \+ Vektor-Datenbank (ChromaDB, FAISS).  
* **LightRAG-Ansatz:** Speichert nicht nur "Regel X", sondern auch "Regel X gehört zu Modul A" und "Modul A wurde ersetzt durch Modul B" (Substitution Mapping).
